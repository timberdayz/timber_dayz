# 月度绩效使用与计算说明

## 给运营团队的简明说明

公司的绩效不是按每天临时计算，而是每个月结束后，统一使用这个月的真实经营数据进行结算。系统先计算店铺，再根据员工负责的店铺生成个人结果，最后进入提成和工资单。

## 一句话理解

```text
月度订单数据 + 月度目标 + 运营评分
→ 店铺总分和排名
→ 个人绩效和提成
→ 工资单
```

## 店铺分数怎么算

店铺满分 100 分：

| 项目 | 分值 | 计算方式 |
|---|---:|---|
| 销售 | 40 | 实际销售额 ÷ 销售目标，最高按 100% 计算 |
| 毛利 | 40 | 实际毛利 ÷ 毛利目标，最高按 100% 计算 |
| 运营 | 20 | 当月运营目标分解中的运营评分 |

例如：一个店铺销售完成 80%，毛利完成 90%，运营得 16 分，则：

```text
销售得分 = 80% × 40 = 32 分
毛利得分 = 90% × 40 = 36 分
运营得分 = 16 分
店铺总分 = 32 + 36 + 16 = 84 分
```

超过目标的部分不会让单项超过该项满分。重点产品暂时不计分，未来如启用会另行通知。

## 排名和预警

所有正式店铺放在同一个月度排名中，按总分从高到低排列。系统再根据排名生成店铺绩效系数，这个系数会影响员工提成。

- 低于 70 分：黄牌提示；
- 低于 60 分：红牌提示；
- 经营天数少于 15 天：只提示数据覆盖风险，不自动扣分，也不自动取消排名。

## 个人目标和收入

员工的个人目标来自自己负责的经营店铺，不需要再单独填写一套脱离店铺的目标：

```text
个人销售目标 = 负责店铺销售目标 × 目标分配比例之和
个人毛利目标 = 负责店铺毛利目标 × 目标分配比例之和
```

目标分配比例表示“店铺目标由几个人分别承接多少”；提成比例表示“利润中的提成比例”。两者互不替代。

```text
员工提成 = max(利润基数, 0)
          × 店铺可分配利润率
          × 员工提成比例
          × 店铺绩效系数
```

负利润不会产生正提成。工资单还会汇总基础工资、岗位工资、绩效工资、提成、津贴和扣款。

## 每月管理员操作

确认数据 → 确认目标和归属 → 重算绩效 → 检查排名预警 → 检查个人结果 → 生成工资单。

运营人员通常不需要操作计算，只需查看负责店铺的目标、达成率、总分、排名和收入结果；发现异常时反馈店铺、月份和具体指标即可。
